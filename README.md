# Cedar Clerk

**Cedar Clerk** is a blog platform for indie creators. User has it's own space to
more effectively develop their games, software or any other pieces of creativity.
Platform provides an AI-powered text editor for different varieties of documents, 
a simple CMS management, a global-scoped and project-scoped glossary and many other 
different utilies which could help user to plan, develop, tell and share their products
and stories of theirs' development.

The main core of Cedar Clerk is it's export utility which supports:

- Personal blog space with unique subdomain (<nickname>.cedarclerk.app)
- Telegram (Richful Posts)
- X/Twitter
- BlueSky
- LinkedIn
