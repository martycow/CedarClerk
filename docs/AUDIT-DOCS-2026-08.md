### A-4. `DECISIONS.md` — распиливаемость

- **Количество ADR: 122** (ADR-001 … ADR-122).
- **Формат единообразен**: все 122 заголовка — уровень `###`. Regex границы:
  **`^### ADR-\d+`** — ровно **122 совпадения** (на уровнях `#`/`##`/`####` — 0). Нумерация в
  заголовках zero-padded до трёх цифр по 099 (`ADR-001`…`ADR-099`), дальше `ADR-100+`; коротких
  форм («ADR-64») нет нигде в файле (0 совпадений `ADR-[1-9][0-9]?[^0-9]`).
- **Без номера — 0, дубликатов номеров — 0, пропусков — 0** (последовательность 001–122 сплошная).
- **Формальных статусов нет.** Слова-статусы встречаются как проза: `Superseded` ×1,
  `superseded` ×2, `Accepted` ×1, `устарел` ×1, `отменён` ×0. Механизм supersession — правило из
  преамбулы (`DECISIONS.md:3`): «a superseded decision gets a new entry that references the old one
  rather than an edit-in-place». Скрипт извлечь статус не сможет — он существует только в тексте
  более поздних ADR (пример: ADR-117 отменяет 105/108 текстом).
- **Внутренние cross-links**: markdown-якорей `](#…)` — **0**; текстовых упоминаний `ADR-\d+` —
  **319** (все 122 номера упомянуты, единый канонический вид). При распиле по файлам **ни одна
  внутренняя ссылка не ломается технически** (они и сейчас не кликабельны), но теряется
  Ctrl-F-навигация по одному файлу — лечится индексом.
- **Не-ADR контент — 2 куска**, наивный распил их осиротит:
  1) преамбула, строки 1–6 (`# Decisions (ADR log)` + правило);
  2) **`## Ownership audit reference (09.07.2026…)`, строки 92–111** — сидит между ADR-017 (:84) и
  ADR-018 (:112); на неё ссылается `ARCHITECTURE.md:98` («see the ownership-audit table in
  `docs/DECISIONS.md`»).
- **Внешние ссылки на файл `DECISIONS.md`: 43 файла**, включая ~20 файлов кода
  (`AdminEndpoints.cs`, `Entities.cs`, `BlogEndpoints.cs`, `Program.cs`, рендереры Core, 8 файлов
  Angular и т.д.) и `.claude/rules/*`. → после распила **файл обязан остаться** (как индекс со
  списком ADR и ссылками), иначе рвутся десятки указателей, в том числе из кода.

**Вывод: распил скриптом безопасен** при regex `^### ADR-\d+` и трёх ручных решениях:
(1) преамбула уходит в шапку индекса; (2) ownership-секция — в отдельный файл (или приложение к
индексу) с правкой одной ссылки `ARCHITECTURE.md:98`; (3) `DECISIONS.md` остаётся индексом.
Правок содержимого самих ADR не требуется: 0 якорей, 0 аномалий нумерации.
