# Backlog — task board

The **only** home of open, not-yet-started tasks. Board rules:

- Canonical line: `- [ ] T-xxx Name — description #tags P1..P3` (P1 = High, P2 = Medium, P3 = Low).
- IDs are stable (`T-xxx` tasks, `Q-xx` open questions) and never reused. Marty's original numbering (B*, N*, I*, NF*, FI*, idea N) stays in descriptions so old references in ROADMAP/DECISIONS keep working.
- `#decision` means Marty's decision is needed first (see the questions table at the bottom).
- Done rows are deleted; what shipped is recorded in `docs/tasks/ROADMAP.md` / `CHANGELOG.md`. The live-verification checklist of already-built things lives in `docs/tasks/TASKS.md`, not here.
