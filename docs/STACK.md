# Стек и расходы

Всё, из чего собран Cedar Clerk, и во что это обходится. Проверено по файлам проекта 13.08.2026.
Версии — из `*.csproj` и `package.json`; **суммы — ориентиры, сверять по счетам**, потому что счёт
знает правду, а документ помнит момент написания.

---

## 1. Бэкенд (.NET 8)

| Пакет | Версия | Зачем |
|---|---|---|
| `Microsoft.EntityFrameworkCore.Sqlite` | 8.0.* | Вся база. SQLite выбран сознательно — одна машина, один файл, `sqlite3 .backup` как бэкап |
| `Microsoft.AspNetCore.Identity.EntityFrameworkCore` | 8.0.* | Аккаунты, куки, хеши паролей |
| `Microsoft.EntityFrameworkCore.Design` | 8.0.* | Миграции (`dotnet ef`) |
| `Telegram.Bot` | 22.10.2 | Бот и публикация: Bot API 10.2, механизм Blocks |
| `Quartz` + `Quartz.Extensions.Hosting` | 3.18.2 | Отложенная публикация, фоновые задачи |
| `SixLabors.ImageSharp` | 3.1.12 | Сжатие картинок, превью, watermark |
| `Anthropic` | 12.35.1 | Автоперевод и AI-правка |
| `Spectre.Console` (+ `.Cli`, `.Testing`) | 0.55.0 | Консоль `cedar` |
| `xunit` + `Microsoft.NET.Test.Sdk` | 2.5.3 / 17.8.0 | 931 тест |

**Чего в стеке нет и это осознанно**: ORM поверх EF, Redis, очередь сообщений, Docker (пока —
`T-151`), сервис-меш и всё остальное, что обычно добавляют «на вырост». Пока приложение живёт на
одной машине, каждый из них добавил бы отказ, а не устойчивость.

## 2. Фронтенд (Angular 21)

Angular 21 (standalone-компоненты, signals), TipTap 3 как редактор — `starter-kit` плюс расширения
для картинок, таблиц, формул, чек-листов и выравнивания. Плюс `@angular/cdk` (drag-drop в настройках
тулбара), `katex` (формулы), `@phosphor-icons/core` (иконки), `rxjs`. Тесты — Vitest, 18 штук.

## 3. Десктоп

Electron 33 + `electron-builder` 25 + `electron-updater` 6. С ADR-117 десктоп — тонкий клиент к
проду плюс агент файловой системы; своей базы у него нет.

## 4. Внешние сервисы

| Сервис | Роль | Что будет, если он ляжет |
|---|---|---|
| **DigitalOcean** | дроплет `cedarclerk-periwinkle` (1 vCPU / 2 ГБ / 48 ГБ, fra1) | всё лежит |
| **Cloudflare** | DNS, туннель (единственный вход снаружи), R2 для off-site бэкапа | сайт недоступен; SSH жив по IP |
| **Telegram** | публикация в каналы, вход, Stars-платежи | посты не уходят, блог работает |
| **Stripe** | подписки и кредиты, деньги приходят на банковский счёт Марти | оплата недоступна, сервис работает |
| **PayPal** | альтернативная оплата (без recurring, ADR-013) | то же |
| **Anthropic** | автоперевод, AI-правка | AI-функции отдают ошибку, остальное работает |
| **Resend** | письма (инвайты на приватные посты) | приглашения не уходят |
| **healthchecks.io** | сторож ночного бэкапа | бэкап идёт, но молча |
| **UptimeRobot** | внешний мониторинг + статус-страница | никто не сообщит о падении |

## 5. Что это стоит

Постоянные расходы, по публичным ценам на 13.08.2026 — **сверить с реальными счетами**:

| Статья | Ориентир | Примечание |
|---|---|---|
| Дроплет 1 vCPU / 2 ГБ / 48 ГБ | ~$12/мес | fra1, самый дешёвый уровень, на котором это живёт |
| Недельные образы дроплета | ~20% от цены дроплета | включено Марти 11.08.2026 |
| Cloudflare (DNS + туннель) | $0 | бесплатный план |
| Cloudflare R2 | $0 | до 10 ГБ бесплатно, наших ~1.2 ГБ |
| Домен `mooexe.dev` | ~$15/год | |
| healthchecks.io | $0 | бесплатный уровень |
| UptimeRobot | $0 | **свой домен для статус-страницы — платный**, поэтому ссылка ведёт на `stats.uptimerobot.com` |
| Stripe | 2.9% + $0.30 с платежа | с $3 подписки это ~13% |
| **Anthropic** | **переменная** | единственная статья, растущая от числа пользователей |

**Итого фиксированных: около $15 в месяц.** Всё остальное — переменное, и опасна там ровно одна
строка: Anthropic. Разбор, почему Pro Plus за $6 может не окупаться, — в `docs/BUSINESS.md` §3.

Комиссия Stripe заслуживает отдельного взгляда: на подписке за $3 она съедает 13%, на $6 — 7.5%.
Это аргумент в пользу годовой оплаты со скидкой (одна комиссия вместо двенадцати), когда дойдут руки
до пересмотра тарифов (`T-152`).

## 6. Чем расплачиваемся за такой стек

- **Одна машина** — нет ни горизонтального масштабирования, ни отказоустойчивости. Осознанно: пока
  пользователь один, это дешевле и понятнее всего.
- **SQLite** — одна запись за раз. Для публикации и редактирования постов этого достаточно с
  огромным запасом; узким местом станет не он, а диск (см. `docs/MULTITENANCY.md`).
- **Медиа на диске дроплета** — вот это упрётся первым, и раньше, чем кажется.
- **Ручной деплой** — `cedar deploy` с ноутбука. CI нет; собирать и выкатывать может только Марти.
