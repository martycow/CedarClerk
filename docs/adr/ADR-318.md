# ADR-318 — A project may exist with no documents

**Status**: DRAFT
**Session**: BR-002
**Supersedes**: ADR-103

## Context

ADR-103 made "at least one document per project" a rule enforced at creation and at document deletion. The new-project prototype (`Docs_CedarClerk/UI_Prototypes/New_project.png`) has a "Start without documents" option, and the owner chose to allow empty projects. The rule also produces the misleading `ProjectNeedsOneDocument` refusal.

## Decision

1. Creating a project with "Start without documents" (and the Empty preset) creates no document.
2. Deleting a project's last document is allowed. `LastDocumentRefusal` and `ErrorMessages.ProjectNeedsOneDocument` are removed.
3. Every screen that assumes a first document handles zero: project overview, Documents, Planner, Builds changelog, Showcase.

## Consequences

- The create transaction becomes simpler.
- Each project screen needs an empty state; `docs/design/UI-INVENTORY.md` records them.
