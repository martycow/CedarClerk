# ADR-144 — The design-system mirror is a re-fetchable cache, not a document

**Context.** Cedar Bench is authored in a Claude Design project, and the port needs it on disk to read against. The mirror is `.design-sync/ds-v2/` — 94 files: `tokens/`, `styles.css`, `assets/`, `ui_kits/`, `guidelines/`, `_ds_manifest.json`, and 22 `.md` files, 21 of them component prompts (`components/chrome/RailHeader.prompt.md`, `components/forms/Button.prompt.md`, and the rest) plus `readme.md`. Beside it, `.design-sync/config.json` names the project it came from (`projectId`, `sourceProjectId`, `shape: "package"`). Two questions had to be answered before Stage 1: where on disk it lives, and whether it is committed.

Both have a guard behind them. `CedarClerk.Tests/DocsFlowGraphTests.cs` enumerates every `docs/**/*.md` — excluding only `docs/adr/`, `docs/archive/`, the map itself and the gitignored `docs/INPUT_PROMPT.md` — and fails when a file is not mentioned in `docs/DOCS-FLOW.md`. Its twin, `Every_mapped_path_exists`, regexes `docs/…\.md` back out of that map and requires each named path on disk.

**Decision.**

1. **The Claude Design project is the source of truth; the local copy is a cache.** Nothing in this repository edits `.design-sync/ds-v2/` — an edit made here has no way upstream and is lost on the next fetch. What the repo keeps of the design system is token *values* in `cedarclerk-web/src/styles.scss`, which stays canonical (`docs/design/DESIGN.md` §Known design debt); the mirror is the reference those values were derived from, not a second declaration of them.

2. **It lives at the repository root, outside `docs/`.** Under `docs/` its 22 `.md` files fall under `Every_live_doc_is_on_the_map`, which would demand 22 rows in `DOCS-FLOW.md` describing files nobody here wrote and the next re-mirror may rename or drop. The precedent runs the same way: `docs/design_handoff_indiedev_core_loop/` is named in six tracked docs (ADR-103, `docs/design/DESIGN.md`, `docs/design/indiedev-design-prompt.md`, `docs/design/UI-INVENTORY.md`, `docs/product/INDIEDEV.md`, `docs/tasks/ROADMAP.md`) and is not on disk — the tests stay green because no map row spells a path inside it. They are not a document set: a prompt file is a component brief that comes back byte-for-byte on the next fetch. Making a fetch into a docs-flow event is a maintenance tax with no reader.

3. **It stays out of git, and out of git means a `.gitignore` entry** — `.design-sync/` is currently untracked but unignored, so a single `git add -A` commits the cache by accident. The entry is part of this decision, not an afterthought.

4. **Its one mention in a tracked doc spells no `.md` path.** `docs/DOCS-FLOW.md` §Модуль инди-геймдева states the placement and the reason in prose. That restraint is load-bearing: a mirror path written there as `docs/…/x.md` would be pulled out by `Every_mapped_path_exists` and required on a fresh clone.

**Rejected.** *Commit the mirror* — it buys diffs and review over content this repository cannot change, at the price of 94 generated files re-landing wholesale on every fetch, in a history nobody would read. *A git submodule* — there is no upstream git repository; Claude Design is not a remote. *Vendor only the parts the port consumes (`tokens/*.css`)* — half a cache is worse than none: the prompt files are what component work is read against, and a partial copy drifts silently while still looking complete.

**Consequence — the cost, taken with eyes open.** A fresh clone does not have the mirror, so any doc citing a mirror path cites something that may be absent, and no test can tell. Nothing in the build reads it: `check-contrast.mjs`, `generate-design-tokens.mjs`, the CLI pipelines and the test suite all ignore `.design-sync/` entirely, so its absence breaks nothing — it simply cannot be verified. `docs/design/UI-V2-PLAN.md` cites mirror paths and is branch-local, dying as its decisions move into ADRs — but the ADRs themselves cite them too, and ADRs are append-only. ADR-138 through ADR-143 each read a value, a line or a file size out of `.design-sync/ds-v2/`, and none of those citations can be checked on a clone without the cache. What keeps that honest is the shape those entries already take: every mirror path in them is attached to the **number** it produced — 2.39:1, 299 124 bytes, 36 glyphs, 63 half-pixel declarations — so the finding survives the cache's deletion even though the path stops resolving. The path is provenance, not evidence, and re-fetching restores it. The exposure is therefore permanent and bounded, not temporary. Recovery is one line: re-fetch the project named by `projectId` in `.design-sync/config.json`. When every V2 decision has an ADR, the mirror can be deleted and nothing the repository needs goes with it.
