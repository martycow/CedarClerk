# ADR-299 — LinkedIn: a post-now connector that carries the document's layout (14.09.2026)

**Context.** T-381 and the research verdict in `RESEARCH-2026-09.md` §T-127: "Share on LinkedIn" is self-serve (`w_member_social`, the versioned `/rest/posts`), tokens live 60 days with no programmatic refresh, and the API Terms of Use (§3.1 item 26) forbid automated posting. The maintainer holds a Client ID and secret and asked for full posting support with the layout preserved as far as LinkedIn allows.

**Decision.**
1. **`linkedin` is a fifth `PublishNetworks` key with `LinkedInPublishTarget` behind it** — the ADR-078 shape unchanged: credentials (`personId`, name, access token, expiry) encrypted on the `PublishTarget` row, no new entity, no migration. Connecting is X's OAuth round trip without PKCE (`/api/publish/linkedin/connect` → `linkedin.com/oauth/v2/authorization` → `/api/targets/linkedin/callback`), keyed by the member id from `/v2/userinfo`; scopes `openid profile w_member_social`. Config: `Cedar:LinkedIn:ClientId`/`ClientSecret`, plus `Cedar:LinkedIn:ApiVersion` because the `Linkedin-Version` header names a YYYYMM that LinkedIn sunsets a year later — a header value that can be bumped in the drop-in beats one that needs a deploy.
2. **The document itself is the post, not a teaser.** LinkedIn takes 3,000 characters, so `LinkedInPostBuilder` renders the whole document with what plain text can carry: blank lines between blocks, `•`/`1.`/`☑` list markers with four-space nesting, curly quotes around a blockquote, a dash line for a rule, `label (url)` for links, footnotes numbered and listed at the end, the YouTube line CedarPlainText already gives the other networks. Headings and bold/italic marks go through the Mathematical Sans-Serif block (`UnicodeStyle`) — the only emphasis a LinkedIn feed renders. That block has Latin letters and digits only, so Cyrillic emphasis degrades to plain text rather than to a half-styled mix; the styling is a builder flag, off by nobody yet. The author's ADR-077 override still wins, and the blog link survives truncation, which happens on a block boundary with an `…` line rather than mid-sentence.
3. **`commentary` is escaped as "little" text.** LinkedIn's field is a grammar (`@[…](urn)`, `#tag`, `{…}`), and every reserved character meant as text — `\ | { } @ [ ] ( ) < > # * _ ~` — must carry a backslash or the post is refused or parsed. `LinkedInLittleText.Escape` does that, leaving a `#` that starts a word alone because that is a hashtag the author meant. The 3,000 limit is measured on the escaped string.
4. **Pictures through the Images API, the blog as an article card.** Up to twenty of the document's local pictures (JPG/PNG/GIF; anything else re-encoded as JPEG under 8 MB) are registered with `initializeUpload`, PUT to the returned URL, and referenced by URN — one as `content.media`, several as `content.multiImage`, each with its alt text. When there is no picture and the draft has a blog page, the post carries `content.article` with the page's title, a two-paragraph description and the OG card rendered by `OgImageEndpoint` as the thumbnail, because LinkedIn scrapes nothing from a URL. A refused card (4xx) is retried once as text only: a 4xx posted nothing, so the retry is the author's post, not a duplicate.
5. **Post-now only, enforced in four places.** `/api/posts/schedule` answers 422 for a LinkedIn target, queue slots refuse a LinkedIn target on create and update, `FillQueueSlotsJob` skips one that already exists, and the editor marks the destination blocking with a plain reason while a time is set and leaves it out of `schedulePost`. The publish queue still carries LinkedIn: a job kicked the moment Publish is pressed is the button, not a schedule.
6. **No refresh, so the expiry is a fact the author sees.** `/api/publish/networks` answers `expiresAt` for LinkedIn accounts (null for every other network); the Settings card prints the date, turns into a reconnect prompt a week before, and the target answers `LinkedInReconnect` (401, not retried) once the token is past. No credit charge — the API is free — and no stats leaf: reading a member's posts is a restricted permission.

**Consequence.** A LinkedIn post is one message with the layout LinkedIn can show and nothing it cannot: tables come out as `|`-joined rows, code blocks lose their monospace, video and audio stay on the blog. Organisation pages, comments and analytics are the vetted Community Management product and a different ADR if ever wanted. Should LinkedIn ever grant programmatic refresh tokens to this app, `LinkedInCredentials` grows a refresh token and X's save-before-use rule applies.
