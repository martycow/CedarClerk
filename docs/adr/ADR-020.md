# ADR-020 — Domain strategy: hybrid (supersedes ADR-017's open style question)
**Context**: ADR-017 decided user blogs would live at some kind of subdomain but left the exact style open (`mooexe.dev` subdomains vs. a dedicated domain) — that specific open question is what this entry resolves; ADR-017 itself is left as-is per this doc's append-only convention.
**Decision** (16.07.2026): Hybrid split. The app/control-plane (editor, auth, API) stays on `cedarclerk.mooexe.dev` via the existing Cloudflare Tunnel (`cedarpi`). Tenant blogs move to a **separate, dedicated product domain** — working name `cedarclerk.app`, **not yet registered**. Rationale: keep Marty's personal identity (`mooexe.dev`, Dev Dairy Diary) separate from third-party tenant content — brand and liability separation, not just a technical routing choice.
**Consequence**: Real infra work is now a recorded dependency, not yet scheduled as a phase step: register the domain; add a Cloudflare zone + wildcard `*.<domain>` routed through the tunnel; extend the Kestrel host-routing already used for `blog.mooexe.dev` (`Program.cs` `MapWhen` on `Host.Host`) to the new domain and to per-tenant subdomains under it. See the dependency note in `docs/ROADMAP.md` near Phase 6.
