# ADR-297 — Compact Telegram sign-in widget

The authentication forms keep Telegram's signed iframe widget. Use its medium
button size and a field-sized corner radius. The host fits the iframe and clips
its corners at the same radius. Telegram declares its own light/dark canvas inside
the cross-origin document, so the parent cannot reliably force its transparent
corners onto light paper through an inherited color scheme. Clipping removes that
canvas outside the button without covering its interactive area.

Google availability remains tied to server configuration. Changes to a systemd
drop-in require daemon-reload and a service restart before credentials reach the
application. No credentials are copied into the repository.
