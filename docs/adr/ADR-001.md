# ADR-001 — Backend: C#/.NET 8 LTS, Rust excluded
**Context**: Choosing a backend language/runtime for a personal project that must run on a Raspberry Pi 4 (armhf).
**Decision**: C# on .NET 8 LTS. Rust was considered and excluded.
**Consequence**: .NET 8 is the only runtime version supported on Bullseye/armhf without extra work; support runs to ~November 2026, tying the runtime upgrade to the planned OS migration (`.claude/rules/production-environment.md`). Rust offered no advantage in this stack and was dropped without further evaluation.
