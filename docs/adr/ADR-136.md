# ADR-136 — One look: Cedar Bench replaces the skin mechanism

**Context.** ADR-120 gave the app a second styling axis, `data-skin`, orthogonal to `data-theme`, on the premise that two looks would coexist: the shipped palette and Forest Workshop. The port to Cedar Bench ends that premise. Bench is not a repaint — it is a shell, a density contract and twenty components, and it is the look the product is going to have. Forest is 1 246 lines in `cedarclerk-web/src/styles/_forest.scss` that recolour app classes (`.btn-accent`, `.chip`, `.status-badge`) the port deletes outright, so the partial outlives its own targets by about one stage. Keeping both means every bench component ships two sets of values and `cedarclerk-web/tools/check-contrast.mjs` runs a second pass over a block it cannot currently see at all.

**Decision.**
1. **Cedar Bench is the only look, and the skin mechanism retires with the port.** Gone: the `data-skin` attribute; the `Skin` union at `cedarclerk-web/src/app/core/theme.service.ts:4` with `setSkin`, `applySkin` and `loadInitialSkin`; the `cedar-skin` storage key at `theme.service.ts:6`; the Appearance control at `shared/appearance-panel.component.html:15-21` and its three strings (`core/i18n/en.ts:1345-1347`, `core/i18n/ru.ts:1310-1312`); `styles/_forest.scss` and its `@use` at `styles.scss:7`. The old `default` palette is not preserved anywhere — its values are overwritten in place.
2. **The light/dark axis survives untouched**: `data-theme`, `ThemeService.theme`/`toggle`/`set`, the `cedar-theme` key, and the constructor application that themes the login page before authentication. It is the only axis with persistence, a pre-auth path and a server-rendered twin (`DesignTokens` → `BlogEndpoints.cs`, `LandingEndpoints.cs`).
3. **The design system's own `data-time="night"` is discarded as a mechanism**, not translated into a third attribute. `[data-time]` is specificity (0,1,0) and loses to `:root[data-theme="dark"]` at (0,2,0), so a verbatim port would fail silently on every token the app's dark block also owns.
4. **Bench values therefore land on the bare `:root` (`styles.scss:9`) and on `:root[data-theme="dark"]` (`styles.scss:178`)** — no partial, no attribute scope. They are the contract, not an overlay on one. Which names are contractual and what they may hold is ADR-137's subject.
5. **This supersedes ADR-120's mechanism clauses**: the `data-skin` axis with its attribute-absent default, the scoped-partial arrangement, and the claim that the injected user accent is beaten by specificity rather than source order. **Four of its findings survive** and are re-stated where they belong: the night derivation — cream paper, only the wood darkens, and the night block must re-assert every token the dark theme flips light-for-dark (ADR-141); the two-layer focus ring at `_forest.scss:419-423`, which is measured and which deleting the partial would otherwise throw away (ADR-140); the self-hosted `@fontsource` faces (ADR-143); and its observation that the contrast checker reads only the two base blocks, which stops being a limitation and becomes coverage the moment bench lives in them. Deleting `_forest.scss` is this ADR's decision, so naming what has to be lifted out of it first is this ADR's obligation; what each rescued piece becomes is the cited ADR's.

**Rejected.** *Bench as a third skin* (`data-skin="bench"`) buys a runtime rollback and pays for it three times: forest survives past the classes it repaints, the contrast checker needs a second pass, and the whole new look sits outside what `tools/check-contrast.mjs` and `tools/generate-design-tokens.mjs` read — both find `:root` in `styles.scss` and brace-match from there, so a scoped block is never contrast-checked and never reaches the blog or the landing page. The selector string itself is the sharper trap: `:root[data-skin="bench"]` contains `:root`, and placing it above the base block re-runs the anchoring incident `styles.scss:1-6` records, where a mention in a comment silently pointed the dark check at the light block. *Freezing the default palette as a rollback switch* was rejected for the same reason plus one: a switch with one position anybody actually uses is a maintained fiction.

**Consequence.** Four costs are accepted deliberately. **There is no fallback look during the port** — the token work lands before the screens, so every unported page renders its own `.page-header`, `.btn-accent` and `.stat-card` rules against bench values from that commit on, and the only way to see the previous look is `git checkout master`; `npm run check:contrast` is the sole thing watching those screens until their stage lands. **A user-visible control disappears**, and a `cedar-skin` entry already in someone's localStorage becomes dead data — not migrated, not read. **The user's accent preset regains authority over the bench accent**: ADR-120 relied on the skin block outspecifying the `:root{--accent:…}` rule injected at `core/appearance.service.ts:124`, and with nothing scoped above the contract that rule now wins on source order. That is the right behaviour for a user setting in the light theme and an accessibility defect at night, where the preset's lightening mix lands on cream paper; ADR-141 measures it and owns the repair. **The four faces stop being optional**: ADR-120's property that the default skin loaded zero font bytes dies with the default skin, and the sixteen `@fontsource` subsets at `_forest.scss:7-22` go down with the partial unless they are moved first, leaving the look in fallback fonts. ADR-143 owns where they land and what they cost. Two doc rows retire in the same commits as the code: `docs/design/UI-INVENTORY.md:122` and `docs/design/DESIGN.md` §Skins.

All of this is survivable because it is contained by the branch, not by a runtime flag. Work happens on `UI_V2`, and `cedar deploy` refuses any branch but `master` and any dirty tree (`CedarClerk.Cli/Pipelines/GitGuard.cs`), so a half-ported app cannot reach production by accident. Reversibility for a *look* is a branch and a tag; the flag-plus-ADR arrangement ADR-101 uses for a feature module buys nothing here, because a look has no half-state worth shipping.
