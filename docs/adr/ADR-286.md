# ADR-286 — One skeleton, held for 300 ms, marking the region busy (05.09.2026)

**Context.** T-184. The motion tokens (`--motion-*`, `--ease`, the reduced-motion clamp) exist,
but every list still said «Loading…» in a `.hint` line while its data arrived, and the admin page
replaced the whole grid with that one line. A placeholder that has the shape of what is coming
holds the layout; a sentence does not. Two questions needed a ruling: how many shapes, and what
to do about an answer that arrives in 60 ms.

**Decision.** One component, `app-skeleton` (`shared/skeleton.component.ts`), four variants —
`text` (lines, the last one short), `card` (avatar plus two lines, the user-card shape),
`avatar`, `table-row` (four cells at the row pitch) — and a `count`. The shimmer is one
`::after` sweep on `--motion-slow × 5` with `--ease`, painted with `--alt` and `--hover`, and
switched off (not clamped to a 1 ms loop) under `prefers-reduced-motion`. The component is the
labelled `role="status"` and sets `aria-busy` on the element it stands in, restoring the
attribute when it leaves.

The minimum display is a rule, and it lives beside the flag rather than in the component:
`heldLoading(flag)` returns a signal that stays `true` for `SKELETON_MIN_MS` (300 ms) after the
source drops, because a component inside `@if (loading())` cannot outlive the `@if`. The hold
registers a `PendingTasks` task, so `whenStable()` in a test waits it out and no test has to
know the number.

**Rejected.** *A per-usage skeleton* — the admin page would have had four hand-drawn ones by
the end of the day. *The hold inside the component (`ngOnDestroy` deferral)* — Angular removes
the host when the branch goes; the component is not asked. *No minimum* — a 60 ms skeleton is a
flash, which is the thing the backlog row names. *A longer minimum* — 300 ms is under the
threshold where a wait is felt, and above the threshold where a change is seen.

**Consequence.** `/admin` uses it for the page load, the audit Load more, and the Landing and
Discovery first opens; the sidebar has no list loading state to convert. The Posts Manager and
the editor are owned by another lane and keep their «Loading…» lines until that lane adopts the
component. `docs/design/UI-INVENTORY.md` carries the component and each usage.
