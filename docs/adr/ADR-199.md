# ADR-199 — Departure Mono is an opt-in editor face

**Context.** The Appearance panel exposes the writing sheet's typeface, and the annotation set asks
for Departure Mono there. ADR-180 deliberately limited the face to instrument readouts because a
pixel font is only sharp at 11px multiples. Leaving it out of the picker after the product request
would make the installed face appear unavailable; exposing it at arbitrary half-pixel sizes would
make it appear broken.

**Decision.** `departure` joins the editor-only `AppearancePrefs.typeface` union and resolves to
`--font-readout`. Selecting it also moves the writing sheet to 22px. While it is selected, the text
size control offers only the exact 11px grid steps supported by the face; selecting another face
restores the ordinary 13–22px half-step range. Existing saved preferences continue to parse through
the same defaults and the public blog remains unchanged.

This supersedes ADR-180 only where it rejected a selectable editor face. Its file ownership,
licence, token name, readout use, and exact-grid requirement remain in force.

**Consequence.** Departure Mono becomes a deliberate authoring view instead of a global typography
change. It can be chosen without soft rasterized strokes, and documents keep their content and
published rendering independent of the author's local editor preference.
