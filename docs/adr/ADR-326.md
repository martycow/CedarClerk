# ADR-326 — The Writer follows the 08.10 mockup: one toolbar row, a Document | Selection inspector

**Status**: DRAFT
**Session**: BR-002
**Supersedes**: ADR-150 (adaptive toolbar rows); the user-customizable toolbar of ADR-035; the automatic-only inspector scope

## Context

The owner supplied a Writer mockup (`Docs_CedarClerk/Reviews/ChatGPT Image Oct 8, 2026, 08_53_49 AM.png`). Today the toolbar fits 34 buttons into one or two captioned rows that each user can rearrange (`ToolbarLayoutJson`); there is no slash command. The editor draws its own Properties panel whose scope follows the cursor automatically, with all groups always open. The frame header shows "Project · kind · N documents" instead of a breadcrumb.

## Decision

1. **Toolbar is one fixed row**: undo, redo | block type | bold, italic, underline | link, bullet list, numbered list, table | "Insert with /" hint, "More ▾". Every other command lives in More, grouped as today's groups.
2. **A `/` slash menu** inserts any block or inline command from the keyboard.
3. **Toolbar customization is removed**: the Settings layout editor, presets and `ToolbarLayoutService` go. `ApplicationUser.ToolbarLayoutJson` stays as a vestigial column (dropping it rebuilds `AspNetUsers`, the same risk as T-146).
4. **Frame header** is a breadcrumb "Project / Documents / Title" with "All changes saved" and the last-edited date on the right.
5. **Properties** has a header with a collapse button and a Document | Selection switch. It jumps to Selection when text, a table or a block is selected; the user can switch back. Document shows Organize (Type, Folder, Series, Tags), Languages (chips, "+ Add", a one-line hint), then collapsible Publishing, Structure, Glossary and Advanced rows with right-aligned summaries, and a footer naming the protected fields. Slug, location and backlinks move into Advanced.
6. The editor has one Properties panel; the shell inspector does not repeat it (closes the editor half of T-390).
7. Version stays under the product name (ADR-324), not at the right end of the top bar.

## Consequences

- The toolbar is predictable and fits the 790px column; power users lose rearranging and rely on More and `/`.
- `docs/design/UI-INVENTORY.md` rows 48–66, 88–105 and the Settings toolbar-layout rows change.
- Editor e2e specs that click toolbar buttons by row move to the More menu or `/`.
