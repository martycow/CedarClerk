# ADR-072 — Icon set: Phosphor, delivered as inlined SVG through one `app-icon` component (Q-12 answered)

**Context** (31.07.2026): Q-12 was the second blocker of Phase 11 and gated T-079. The incumbent is `@lucide/angular` ^1.23.0, used as a directive on a bare element — `<svg lucideTrash2 class="icon-sm">` — with icons imported per component across 15 TypeScript files, 79 distinct icons in 203 places. Candidates were Lucide (stay), Phosphor (MIT, six weights) and Tabler (MIT).

**Decision**: **Phosphor.** Marty chose it, and the reason it fits rather than merely being a change: six weights (thin → fill) give the "larger and bolder" reading he has asked for before *without* introducing a second icon family, and its rounder, softer terminals sit with the warm-editorial direction of ADR-071 better than Lucide's uniformly geometric stroke. Tabler was declined as a lateral move — close enough to Lucide in character that migrating 203 call sites would buy nothing visible.

**Delivery mechanism** — three published packages exist and they are not interchangeable (verified on npm 31.07.2026: `@phosphor-icons/core` 2.1.1, `@phosphor-icons/web` 2.1.2, `@phosphor-icons/webcomponents` 2.1.5). The choice is **`core` (raw SVG assets) behind a single `app-icon` component**, mirroring the existing `app-brand-icon` (ADR-054) rather than inventing a second pattern:
- The **icon font** (`web`) was rejected: it ships the whole font regardless of how many icons are used, and a font glyph is a poor host for the `aria-label`/tooltip work T-080 is about to do on exactly these elements.
- The **web components** package was rejected: it needs `CUSTOM_ELEMENTS_SCHEMA` on every component that renders an icon, which switches off Angular's template type-checking for that component's whole template — a real cost paid across 15 files to avoid writing one wrapper.
- One wrapper component also means **weight and size are props bound to tokens**, so "make the icons bolder" stays a one-line change instead of a fourth sweep through 203 call sites.

**Consequence (superseded in part by ADR-073)**: T-079 is unblocked. It is not only a set swap — the same pass fixes the measured inconsistency behind it: `.icon` is declared in **9 files with three different values** (15/18/20px) and `.icon-sm` with two, which the new `--icon-sm/md/lg` tokens replace, plus **10 glyphs that are not from any icon set at all** (`☾ ✦ ◷ ⤢ ¶ ⏰ 👍 👎 ☰ ↑`) rendering in the system emoji font and therefore looking different on every OS. Lucide stays in `package.json` until the last call site moves, since a half-migrated app needs both. Because the base direction is a continuation rather than a reversal, the migration (T-081) can proceed screen by screen with the Phase 10 smoke suite green after each one, instead of needing a big-bang cutover — which is what ADR-070 built the suite for.
