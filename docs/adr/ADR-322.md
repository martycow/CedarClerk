# ADR-322 — Workspace tools are project-scoped

**Status**: DRAFT
**Session**: BR-002
**Supersedes**: the account-wide sidebar entries of ADR-306

## Context

With no project open, the sidebar shows Documents, Assets, Calendar and Posts pointing at account-wide pages. With a project open, Documents and Assets are filtered, while Calendar and Posts stay account-wide. The owner wants Documents, Assets, Calendar and Publishing to exist only inside a project.

## Decision

1. Documents, Assets, Calendar, Publishing, Metrics and Forms appear in the sidebar only when a project is selected, and show that project's content only.
2. Their routes require a project; opening one without a project redirects to the Projects Hub.
3. `ScheduledPost`, `QueueSlot` and the stats queries filter by the draft's project.
4. The Library group (Glossary, Presets, AI operations) stays account-wide.

## Consequences

- No account-wide view of all scheduled posts remains; a cross-project calendar would need a new decision.
- Posts in no project become unreachable from these pages, so every document must belong to a project (ADR-306 backfill already does this).
