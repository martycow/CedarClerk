# ADR-104 — Десктоп: Electron поверх существующего сервера как sidecar (10.08.2026)

**Context**: бриф просит десктопное приложение — прямо названа причина: «Asset management will definitely need some local application». Строка `T-010` висела в бэклоге как Low с формулировкой «на базе существующего кода» и без всякой механики. Выбор сделан Марти 10.08.2026 из четырёх вариантов (Electron+sidecar, Tauri+sidecar, только PWA, нативный Avalonia/MAUI).

**Decision: Electron-оболочка запускает существующий `CedarClerk.Server` как локальный процесс и открывает в окне тот же Angular SPA.** Ни серверный код, ни фронтенд не форкаются. Механика целиком — `docs/DESKTOP.md`.

**Почему не Tauri**: экономит ~140 МБ дистрибутива и заметную долю памяти, но приносит незнакомый Марти стек (Rust) и различия WebView между ОС — а весь смысл решения в том, что оболочка тонкая и её почти не надо разрабатывать. Экономия размера не окупает второй незнакомый инструмент в проекте, который и так тянет .NET + Angular + TipTap.

**Почему не PWA**: не решает задачу, ради которой десктоп заводится. Браузер не даёт индексировать папку Unity-проекта — File System Access API требует пользовательского жеста на каждую папку и не работает в Safari/iPad, то есть Asset Manager остался бы работать только с загруженными файлами.

**Почему не нативный клиент (Avalonia/MAUI)**: редактор — это TipTap, то есть WebView в любом случае, а весь остальной UI пришлось бы написать заново и потом вести в двух экземплярах. Это форк фронтенда под другим именем, чего ADR-101 избегает специально.

**Ключевая экономия**: `CEDAR_DATA_DIR` уже существует и уже управляет расположением SQLite и медиа (systemd-drop-in на Pi, `.claude/rules/production-environment.md`). Десктоп задаёт ту же переменную в `%APPDATA%/CedarClerk` — и по части хранения серверный код не меняется вообще. Одно исключение найдено при написании этого ADR: адрес прослушивания зашит в код (`app.Run(Consts.URLs.Localhost)`, то есть `http://localhost:8080`), а не берётся из конфигурации, поэтому `ASPNETCORE_URLS` им перекрывается. Десктопу нужен свободный порт — значит, ровно одна строка `Program.cs` становится конфигурируемой, с прежним значением по умолчанию. Бот на десктопе выключается сам, потому что без токена `TelegramBotService.IsRunning` уже возвращает false by design; это не удобство, а защита от 409 (`.claude/rules/telegram-bot.md`), которая иначе стреляла бы каждый раз, когда Марти открывает десктоп при живом Pi.
