# ADR-298 — Forest authentication screens

The selected Forest atelier image replaces the two-column authentication spread.
A centered paper sheet, separate botanical ornament, raster forest backdrop,
coral bookmark and shared page header/footer cover login, registration, external
completion and password recovery. The approved logo remains the source SVG.
The header owns language and theme controls. Long forms scroll naturally; mobile
layout keeps the controls accessible without shrinking text or clipping the sheet.
Auth-specific semantic tokens preserve the reference's light paper in both themes.

Google and Telegram precede the email form. Telegram uses the existing
TelegramLinkService script loader and Telegram.Login.auth popup API, with the
existing signed payload endpoint. Public health adds only the bot's numeric ID.
No bot secret is exposed, no write access is requested for login, and account
linking keeps its existing authenticated endpoint and permissions. Scripts preload
before the gesture; blocked popups, script failure, cancellation and component
teardown have explicit handling. The old iframe presentation is removed.

The existing input component gains an opt-in password visibility control and
label action slot; other consumers retain their existing behavior and styling.
Validation covers form navigation, keyboard use, provider outcomes, both languages,
themes and narrow screens, alongside a comparison to the selected visual.
