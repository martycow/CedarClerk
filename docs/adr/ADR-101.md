# ADR-101 — Indie gamedev is a module inside one codebase, not a fork (10.08.2026)

**Context**: Marty's brief turns the product from "write a long post → publish to social networks" into an indie game developer's toolkit, where a post is just one document type among many. The temptation to split this into two products is real: half of the new entities (tasks, assets, sprints) have nothing to do with publishing. The brief answers this directly: "one codebase, one installation, the base lives as 'role' or 'module', not as fork".

**Decision: one codebase, one process, one database; the module is a set of endpoints and screens behind a flag, not a separate context.**
- Backend: `CedarClerk.Server/Modules/IndieDev/` with its own `XxxEndpoints` classes following the existing convention, registered in `Program.cs` behind the `Cedar:Modules:IndieDev` flag.
- Frontend: `cedarclerk-web/src/app/modules/indiedev/` with lazy routes — the mechanism is already in place, all routes moved to `loadComponent` in T-092/ADR-076, and the cost of a disabled module is zero: its chunks simply don't load.
- The flag reaches the client in the `/api/me` response; the guard hides menu items, not just pages.

**The DB schema is shared, and that's not a compromise.** A second `DbContext` would give a separate set of migrations on top of the same SQLite file — that is, two independent `Database.Migrate()` calls at startup against one database, which `.claude/rules/ef-migrations.md` would not survive. More importantly: a `Draft` must belong to a project, and a task must reference a document. The boundary between contexts would run exactly along the relations the module is being built for.

**What the flag does NOT do**: it does not turn existing screens into different ones. The editor, `/drafts`, `/posts`, `/settings` work with the module enabled exactly as they worked before — the module adds, it doesn't replace. This is the reversibility condition: if the business model doesn't work out (the brief explicitly allows for deleting the `indiedev_module` branch), turning the flag off returns today's app whole.
