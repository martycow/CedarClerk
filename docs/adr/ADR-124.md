# ADR-124 — OG/Twitter-meta на блоге: политика приватности и абсолютные URL (18.08.2026)

**Context.** Страницы постов блога не эмитят ни одного meta-тега — ссылка на пост в Telegram/X/Discord разворачивается голой строкой, что бьёт по каналу привлечения №1 (`docs/product/BUSINESS.md` §6, гейт №11). При этом блог несёт приватные и полупубличные посты, защищённые гейтом, watermark'ом и copy-protection — meta-теги, собранные без политики, стали бы каналом утечки того самого контента (T-174; сессионный бриф из INPUT_PROMPT требовал политику решением, а не кодом).

**Decision 1 — политика есть функция двух флагов поста, и ничего больше.** `f(IsPrivate, IsListedWhilePrivate)`: приватный непубличный пост **не эмитит meta вовсе** (ни title, ни description, ни image — ноль `og:` на странице, на гейте и на 404); полупубличный (`IsPrivate && IsListedWhilePrivate`) — **только `og:title` + статичная заглушка-картинка**, без description и без обложки из контента; публичный — полный набор (og/twitter/canonical/hreflang/article-времена). **Авторизация читателя политику не расширяет**: краулер с валидной инвайт-cookie — всё ещё краулер, и превью не должно зависеть от того, чьими глазами страницу увидел бот.

**Decision 2 — canonical по языковым версиям: каждая версия self-canonical.** Основной язык — `/{slug}`, перевод — `/{slug}?lang={l}`; hreflang-кластер связывает их все, `x-default` — основной язык. Схлопывать переводы в один canonical значило бы прятать их от индексации, а переводы здесь — первоклассный контент (ADR-064/065).

**Decision 3 — абсолютные URL строятся только как `https://` + хост из конфига** (`Cedar:BlogHost` с fallback на `Consts.URLs.BlogHost`), никогда из запроса: TLS терминируется на Cloudflare, Kestrel слушает loopback по HTTP, `UseForwardedHeaders` в проекте нет — `Request.Scheme` в проде честно отвечает `http`, и «правильный» вывод схемы из заголовков добавил бы middleware ради того, что конфиг знает и так. Две существовавшие const-only точки (`siteUrl` в RSS и база медиа-путей рендерера) приводятся к тому же конфиг-паттерну.

**Decision 4 — источники полей.** `og:description` — из `CedarPlainText.Paragraphs` (прозаические абзацы, тот же источник, что у тизеров X/Bluesky), обрезка ≤200 символов по границе слова; не `TipTapTextNodes.ExtractTexts` — тот сметает ячейки таблиц и подписи. `og:image` — первая картинка документа (`CedarImageRefs.Collect`) → аватар владельца → статичная заглушка `/og-default.png` (1200×630); у полупубличного — всегда только заглушка. `article:published_time` — `BlogPublishedAt` (семантика первой публикации, при перепубликации не переписывается), `article:modified_time` — `UpdatedAt`.

**Consequence.** Сборка meta живёт чистым билдером в Core (`OgMetaBuilder`: строки на входе, экранированный HTML на выходе, политика — enum) и покрывается юнит-тестами на эскейпинг/политику/обрезку; страницы, где meta быть не должно, не «фильтруются», а просто не получают ничего — пустой параметр `PageShell` по построению. Кэш превью Telegram живёт долго — повторная проверка той же ссылки идёт через `@WebpageBot` или `?v=2`.
