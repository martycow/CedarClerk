# ADR-319 — The Personal project can be deleted

**Status**: DRAFT
**Session**: BR-002
**Supersedes**: none (behaviour was undocumented in `DocumentProjects.cs`)

## Context

Every account gets a "Personal" project with a fixed per-user id (`DocumentProjects.PersonalId`). Deleting it is refused with the unrelated `ProjectNeedsOneDocument` message, so an owner whose only project is Personal cannot delete it. Deleting any other project moves its documents and assets into Personal and recreates Personal if needed.

## Decision

1. Personal is deletable like any project.
2. Deleting Personal deletes its documents and its project-filed assets. The confirmation dialog states the counts and requires typing the project name.
3. Deleting another project still moves its documents and assets into Personal; Personal is recreated only at that moment.
4. Errors from project deletion are shown inside the settings dialog, not behind it.

## Consequences

- An account can have zero projects; the Projects Hub empty state covers it (ADR-318).
- Deletion is irreversible apart from the nightly backup; the dialog says so.
