# ADR-215 — The landing is drawn on the bench, and its prose is data while its numbers are code

**Context.** The landing page at `/` was the last surface still wearing the pre-bench look: a
centred hero, four flat cards, a plain price table. Everything else a stranger can reach — the blog,
the app, the ruler under both — moved to Cedar Bench (ADR-136 and the ports after it), so the front
door was the one place where the product's own material vocabulary did not appear. A Claude Design
canvas (`Cedar Clerk - Landing.dc.html`) drew what it should look like instead: a wood rail across
the top, paper sheets pinned at an angle, brass, a stamp for a kicker, a shelf board for the
roadmap, a ruler for the footer.

The mock also arrived carrying **copy**, and that is where the harder decision was. It claimed 78
subscribers, a beta "this autumn", a self-hosted product, six languages, `$5`/`$12` pricing and a
five-step founding story. Every one of those is either false about Cedar Clerk today or unknowable:
the product is a hosted SaaS with invite-only registration, nine content languages, `$3`/`$6`
pricing, and no announced date. Prototype copy is a stand-in for length and rhythm, not a claim —
but shipped verbatim it becomes one.

**Decision.** Two rules, and the whole design of the page follows from them.

**One: the page is drawn from the served design tokens, not from copied hex.** The mock's private
token names map onto the ones `DesignTokens.generated.cs` already carries, and the handful that were
missing were added to `tools/contract-tokens.mjs` rather than pasted as values — bare bench wood
(`--wood*`, `--shelf-frame`, `--sign-tile-*`, `--grad-sign-tile`, `--shadow-shelf`), the rail's
height and soft ink, the panel-header height, and `--font-note`. This is T-101's argument reapplied:
the blog once carried its own copy of the palette and was a shade behind for a whole contrast pass,
and a landing page with its own copy would drift the same way. `--rust` and `--wood-edge` are
deliberately **not** added, because they are `--danger` and a rail edge under a second name, and the
list's own rule is that a synonym does not earn a place.

The same argument settled the icons. The old page inlined four Phosphor paths copied by hand into a
C# array. `tools/generate-icons.mjs` now emits `CedarClerk.Core/Icons.generated.cs` alongside the
TypeScript it already produced — the regular weight of all 106 glyphs, with ADR-214's optical
viewBoxes — so the server draws the same pencil the app does, out of the same generator.

**Two: what the code enforces stays in the code; what only a person can judge becomes data.**

- **Code**: prices (`Consts.Plans`), channel and storage limits (`PlanLimitations`), the language
  count (`Languages.ContentLanguages.Count`), the network count (`PublishNetworks.All.Count`), the
  twelve feature cards. These are claims the product must keep, and a hand-written copy of one is
  wrong the first time the limit moves. The old page already did this for prices; it is now also
  true of the two counts it got wrong — it said six languages where the code says nine.
- **Data**: the headline, the kicker, the standfirst, the note in the margin, the screenshots and
  their captions, the roadmap and the founding story. `LandingSettings` is one row holding them, and
  the admin panel's new Landing tab edits it.

Every editable string is nullable and null means "use what the code says", so an install that never
opens the tab still renders a complete page. **The roadmap and the story ship switched off**, and
the social-proof line ships empty — that slot is shaped to hold a number about other people, and an
invented one makes everything above it read as invented too. The mock's versions of all three are in
this repo's history and nowhere on the page.

Three smaller consequences worth naming:

- **Screenshots are uploaded, and they live in the data directory**, served at `/landing-media/`.
  Not `wwwroot`, which `cedar deploy` replaces whole and would take them with it; not `/media/`,
  which is owner-scoped and would be asking who is looking at a page whose whole point is that
  nobody is signed in. The stored name is generated (`shot_<guid>.png`), so a name from a
  screenshot tool never reaches a URL, and the bytes behind a name never change — which is what
  makes the immutable cache header on them honest.
- **The language switch is two links, not a script.** `?lang=ru` and `?lang=en` beat the browser's
  header; a language is a different document, not a different state of one. The response also gained
  `Vary: Accept-Language`, which it needed before this change and did not have: without it, the edge
  cache serves the first visitor's language to the next.
- **The page now reads the database on the anonymous root request.** That is one indexed lookup
  behind a five-minute edge cache, and it is what `TenantRoutingTests` had to grow a `CedarDbContext`
  for — the routing tests build the real middleware chain, so the pipeline's dependencies are theirs
  too.

**Consequences.** The front door is made of the same wood as the room behind it, and the numbers on
it cannot disagree with the code that enforces them. The cost is a table, a migration and an admin
tab — and a standing obligation the tab makes visible rather than removes: the roadmap, the story
and the proof line are blank until somebody with the standing to write them does.

**Alternatives rejected.** Rebuilding the landing as an Angular route would have reused the bench
components directly instead of restating them in CSS — and would have made a stranger download the
application bundle to read a headline, on the one page that has to be indexable. The reason the page
is server-rendered has not changed. Keeping the mock's copy and marking it "sample" was considered
for about as long as it takes to imagine the page being seen.
