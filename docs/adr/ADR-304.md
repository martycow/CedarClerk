# ADR-304 — Remove the MooTool `cedar` console

**Status**: DONE

## Context

The primary development machine is now macOS. The `cedar` console (ADR-291, MooTool `modules/cedar`) was built and installed through PowerShell scripts, Visual Studio Build Tools and Windows paths. It does not run on the new machine. `cedar.json` in this repository only configured that console.

## Decision

Remove `cedar.json`, `docs/for_user/operations-console.md` and every instruction that routes work through `cedar`. ADR-291 is superseded. Until a replacement exists, build, test and deploy use `dotnet`, `npm` and `ssh` directly (`AGENTS.md` §Key commands).

A new cross-platform Rust/Ratatui CLI (`T-393`) takes over the same duties. It must run on macOS, Linux and Windows without PowerShell.

## Consequences

- The deploy guards the console enforced (master only, clean tree, version tag, health check, `LIVE` tags, `app.prev` rollback) are manual until `T-393`.
- The test that read `cedar.json` to prove local runs disable the bot is removed. The whitespace-token test remains.
