# ADR-303 — Empty language versions need a full translation

**Status**: DONE

## Context

`Start empty` creates an empty paragraph and stores the current source snapshot. When
the source also has one paragraph, incremental translation can align the snapshot and
reuse the empty target paragraph. An explicit re-translation then succeeds without
producing translated text.

## Decision

If the existing translation contains only empty or whitespace-only paragraphs and the
current source has text, incremental planning returns the existing full-translation fallback. This applies
to stored empty versions as well as newly created ones, without a data migration.

Partially written translations retain the existing block alignment and reuse rules so
manual text and intentionally empty blocks are preserved. A source without text keeps
the existing behavior. The caller still owns confirmation, provider execution and saves.

## Verification

Cover one and multiple empty paragraphs, whitespace-only text, partially written targets,
and sources without text. Verify first-time translation separately from re-translation of
a version created through `Start empty`.
