# ADR-099 — Schedule is a publish property, not a Telegram one (09.08.2026)

**Context**: Marty's request. The "Schedule send" block lived inside the Telegram panel (ADR-096 left it there as a "parameter of its own network"), and that was true right up until the networks became four. Deferring a post to X or Bluesky wasn't possible at all, and the "split into thread" checkbox next to the time field was silently ignored: a scheduled send went through `PostEndpoints.PublishAsync` with no thread support whatsoever.

**Decision: scheduling is a separate step of the window ("When"), shared across all checked networks.** The set time changes the meaning of the single Publish button for every publish target at once, not for one.

**`ScheduledPost` is addressed by target, not by chat.** The row gets a `TargetId` (`PublishTarget`, ADR-078) and `Network`; `ChatId` stays populated for Telegram — the ownership check and the channel caption in the Posts Manager run off it — but it stops being the target's identity. Rows written before this column publish via the old path: `TargetId == null` is exactly the "legacy" marker, not an error.

**Timed sending goes through `PublishToTargetAsync`, not through the `PublishJob` queue.** The queue (ADR-081) exists so an HTTP request doesn't have to wait on the network; a Quartz job has no such problem — it makes no one wait. A direct call preserves the row status's honest semantics: `Sent`/`Failed` with a real error text, not "queued" with an unknown outcome. The price is that a scheduled send gets no queue retries.

**There are no threads in scheduling, and the window says so.** This isn't a loss: there never was one — the thread toggle simply never reached a scheduled send. Now, with a time set, it's disabled with an explanation, instead of pretending to work.

**The blog isn't scheduled.** The blog is deliberately not a publish target (`docs/ARCHITECTURE.md`), so there's nothing to schedule; with a time set, a checked blog is published immediately, and the "When" step says so in a line of text.
