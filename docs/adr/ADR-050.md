# ADR-050 — Finishing the UI translation: what the dictionaries hold, and what stays English
**Context**: ADR-044 shipped the localization mechanism plus three screens. This closes the rest — `/posts` and its stats/comments tab bodies, Settings, the editor (the largest by far: toolbar tooltips, export modal, AI dialogs, new-draft dialog) and the debug console.
**Decision** (27.07.2026):
- **Cycling status messages became dictionary arrays.** `TRANSLATE_STATUS_MESSAGES`/`EXPORT_STATUS_MESSAGES`/`BLOG_STATUS_MESSAGES` were module-level `const`s indexed by elapsed seconds; they now live in `editor.statuses.*` as plain string arrays and are indexed the same way. The list length is free to differ per language, since the code takes `list.length` rather than a fixed count.
- **Plural forms are functions, not templates** (established in ADR-044 and used again here for request counts and connected-channel counts) — Russian needs three forms where English needs two, and `{n}` interpolation cannot express that.
- **Deliberately NOT translated**: brand and product names (Cedar Clerk, Telegram, Stripe, PayPal, YouTube, Notion…), plan tiers (Free / Pro / Pro Plus), language endonyms in the picker, and `freeAttributionText` — that last one is *published content* mirroring `Consts.Signatures` server-side, not UI chrome, so translating it would change what appears at the bottom of real posts.
- **A second `t`-shadowing bug was hit and fixed the same way as the first**: `@for (t of tagList())` in the editor shadowed the dictionary accessor, producing "this expression is not callable" at build time. Loop variables named `t` are now renamed to `tag` wherever they exist (`/drafts` and the editor), and both carry a comment saying why. Worth knowing for any future template: `t` is reserved.
**Consequence**: **Server-side text is still English** — `ErrorMessages.cs` and every `{ error }` body reaches the UI untranslated, so a Russian interface still surfaces English failure text; this is the single biggest remaining gap and needs an `Accept-Language` pass on the endpoints. `/terms` and `/privacy` remain English on purpose (unfinished `[BRACKETED]` legal drafts). The German layout requirement from B26 is still a pending CSS pass, not a third dictionary — the tab strips added since carry `overflow-wrap: anywhere` and no fixed widths, but nothing has been checked against genuinely long words. The Russian wording itself has not been proofread in a browser screen by screen.
