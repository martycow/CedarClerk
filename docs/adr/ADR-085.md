# ADR-085 — The landing page is server-rendered and reads its prices from the code (T-009)

**Context** (01.08.2026): `cedarclerk.mooexe.dev/` sent everyone to the login form. A stranger arriving at the product had no way to learn what it was.

**Decision: server-rendered HTML at `/`, not an Angular route.** This is the one page whose job is to be found and read by someone who has never heard of the product, and making them download a 531 kB application bundle to read a headline is the wrong trade. The blog already proves the pattern in this codebase. It is **middleware, not a mapped endpoint**, so a request carrying an Identity cookie falls straight through to the SPA — an author who types the address wants their drafts, and an endpoint would have to know where `index.html` lives and hand it back itself.

**Every number comes from the code that enforces it** — `PlanLimitations` for channels and storage, `Consts.Plans` for prices, `PlanLimitations.AiDailyLimit` for the AI quota. A hand-written price table is wrong the first time a limit moves, and a pricing page that lies is worse than no pricing page. The section says so out loud, which is also a small argument for trusting the rest.

**Colours come from the app's own stylesheet** through the generated `DesignTokens` (T-101), and the four card marks are real Phosphor paths from the icon set the app draws with — inlined, because a landing page that waits on a request to draw its own bullet points flickers.

**The screenshot is real.** It is generated by the audit harness from a seeded post written to be worth reading, captured on the blog page rather than in the editor: the editor's chrome carries an account email, and a marketing screenshot with `e2e-admin@local.test` in the corner is worse than none.

**Language follows `Accept-Language`**, defaulting to Russian — the product's own default, and its author's.

**A regression this shipped with, caught by the smoke suite within the hour**: the first version matched `/` on *every* host, so the blog's own index — its homepage — was quietly replaced by the marketing page. The blog host is excluded by name now, and a test asserts it. This is exactly the class of mistake that made Phase 10 build the suite.

**Not built**: an editor screenshot (its chrome is account-specific), testimonials (there are none), and a feature list longer than four items. The page says what the product does, what it costs and who makes it, and stops.
