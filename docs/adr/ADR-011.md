# ADR-011 — Rejected: live Telegram-preview bubble and right "Publish" panel
**Context**: An earlier UI mockup included a live Telegram-style preview bubble and a dedicated right-hand "Publish" panel.
**Decision**: Both explicitly rejected by Marty (the preview bubble before the Cabin redesign session even started; the Publish panel during it, called "pointless"). Export status now surfaces inline inside the Export popover only.
**Consequence**: There is currently no preview-panel component anywhere in `cedarclerk-web/src/app` — confirmed absent from the codebase (15.07.2026 audit). If "add a preview panel" comes up again, it's a new feature request, not a bug fix — the absence is intentional.
