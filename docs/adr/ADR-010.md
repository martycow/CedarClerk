# ADR-010 — Settings stays as an Account popover, not a new tabbed modal
**Context**: Phase 6 brief proposed a Settings window with Account/Channels/Plan tabs.
**Decision**: Not built that way. The existing Account popover (under the topbar avatar) was extended in place instead. Channels stayed in its own dedicated topbar popover — Marty had already rejected merging Channels into a shared side panel earlier in Phase 4 and reverted that attempt once.
**Consequence**: There is no single "Settings" surface — popovers are the established UI pattern for this kind of secondary UI in this app; don't reintroduce a tabbed-modal Settings without checking this decision first.
