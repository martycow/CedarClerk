# ADR-110 — «Куда ушёл пост» читается из очереди публикации, а не из новой таблицы (11.08.2026)

**Context**: Марти опубликовал тред из 25 частей в X и сообщил две вещи — прогресса не было видно, и ссылок на созданные посты он не нашёл нигде. Проверка по продовой базе: все 25 частей `Succeeded`, у каждой записан `PublicUrl`, весь тред ушёл за **17 секунд**. То есть бэкенд отработал полностью, а оба симптома — во фронте.

**Найдено три дефекта, и ни один из них не про публикацию как таковую:**

1. **Прогресс трека не обновлялся вообще.** `awaitJobs` принимает колбэк `onProgress`, который перерисовывает чипы частей на каждом опросе — и телеграмный путь его передаёт, а путь коротких сетей (X, Bluesky) **никогда не передавал**. Чипы рисовались один раз, все «ожидает», и разом переключались в конце. Помощник `reflectJobs` к тому же умел адресовать только строки `tg-<lang>`, так что передать колбэк было и нечем — теперь он адресуется по id шага и годится любой сети.
2. **Счётчик «7/25» был невидим в обеих темах.** `.pr-count` красился в `--alt` — это токен **поверхности**, а не текста: #EFECE4 на #FCFBF8 в светлой, #2F2C23 на #2B2820 в тёмной. Автопроверка контраста этого не поймала, потому что проверяет заданные пары ролей, а не произвольные сочетания в CSS.
3. **Ссылки исчезали.** Тост с результатом живёт **внутри** окна экспорта, окно прогресса стоит поверх него, и тост удалял сам себя через 10 секунд. То есть досмотреть публикацию до конца и закрыть чеклист означало не увидеть ничего. Десяти секунд не хватает, чтобы прочитать ссылку, — их едва хватает, чтобы её заметить.

**Decision: «где лежит опубликованное» читается из `PublishJobs`, а не из новой сущности.** Каждая строка очереди уже хранит `PublicUrl`, который вернула сеть. Заводить рядом таблицу «опубликованные посты» значило бы писать второй раз то, что уже записано, и получить два источника правды, расходящихся при первой же ошибке. Новый `GET /api/publish/published` отдаёт по строке на каждое место, куда версия ушла, и его читает Posts Manager — единственное место, переживающее закрытие редактора.

**Только часть 0.** Публичный адрес треда — его голова; 25 ссылок на один тред это не список постов, а список ответов. `PartCount` едет рядом, чтобы интерфейс мог сказать «тред из 25 сообщений».

**Побеждает новейшая** запись на каждую пару (черновик, сеть, язык, аккаунт): для читателя перепубликация заменяет пост, поэтому пять попыток иначе дали бы пять ссылок на одну и ту же вкладку.

**Успех без публичного адреса в список не попадает** — телеграм-канал без `@username` опубликован, но ссылки предложить не может, и строка с пустым `href` была бы мёртвой кнопкой. Это ровно тот случай, который ADR-065 уже находил трактуемым как «никогда не публиковалось»; здесь он трактуется как «опубликовано, ссылки нет».

**Урок, который дороже трёх правок**: у публикации не было ни одного места, переживающего закрытие модального окна. Прогресс, результат и ссылки жили только в том окне — а окно закрывается. Ценность, созданная действием, обязана иметь адрес, по которому её можно найти назавтра.
