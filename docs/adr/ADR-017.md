# ADR-017 — Blog subdomain strategy decided but not yet built
**Context**: Phase 6 planning (§1.1) decided user blogs would live at `<slug>.` subdomains (style TBD — `mooexe.dev` vs a dedicated domain) via Cloudflare wildcard, with custom domains reserved for a paid tier.
**Decision**: Direction agreed, **implementation deferred** — out of scope for the Phase 6 session that made the call. Confirmed by code audit (15.07.2026): `Entities.cs` has no user-level subdomain/custom-domain field, only `Draft.BlogSlug` (a per-*post* slug on the single `blog.mooexe.dev` host).
**Consequence**: Don't assume multi-tenant blog subdomains exist yet — there is currently one blog host serving all users' published posts under shared per-post slugs.
