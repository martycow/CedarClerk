# ADR-324 — Shell chrome after the 0.25.1 review

**Status**: DRAFT
**Session**: BR-002
**Supersedes**: the account-menu contents of ADR-306; the sidebar-head toggle position

## Context

The top bar shows logo, name/version, project switcher and menus; the logo is not a link, the sidebar toggle sits in the sidebar head, and Log out, Feedback, Fullscreen and Admin live in the account popover.

## Decision

1. Top bar, left to right: Cedar Clerk logo (links to the Projects Hub), name with version beneath, project switcher, sidebar expand/collapse, menu bar. Right end: Fullscreen, Log out.
2. Sidebar bottom row: avatar trigger, then a Send feedback icon button with a tooltip.
3. The avatar popover shows account name, email, avatar, plan and credits, with Settings and Log out buttons. Log out exists in both places.
4. Admin is a sidebar entry, visible to admins only.
5. The `/projects` page is named "Projects Hub". Its default banner is a minimal pattern, not the tree illustration.

## Consequences

- `docs/design/UI-INVENTORY.md` rows 131, 138, 154, 158–160 change.
- File › Sign out in the menu bar is removed as a third copy.
