# ADR-310 — Resolve Discovery cover filenames on the blog host

## Decision

Discovery resolves stored media filenames to `https://{blog-host}/media/{filename}`.
Root-relative paths resolve on the same owner blog host. Absolute external image URLs
remain unchanged. Empty covers retain the existing fallback. Apply the resolver to
Discovery snapshots so the featured stage, cards and landing preview agree.

## Rationale

Draft cover storage accepts bare asset filenames. Rendering those directly in `src`
makes the browser request the application root, which returns 404. Public media still
passes through the existing tenant media gate; this changes URLs, not access rights.
