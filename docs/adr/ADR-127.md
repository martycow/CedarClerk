# ADR-127 — Медиатека v1: страница /media, удаление со сканом, paste/drop (18.08.2026)

**Context.** T-177: загруженные файлы живут только внутри конкретного черновика — нет места, где видно «все мои файлы», нельзя переиспользовать картинку без повторной загрузки (каждый paste создаёт новую строку `Asset` и ест квоту повторно), нельзя удалить ничего, кроме как руками на сервере. Существующие дома не вмещают owner-wide библиотеку: «Files» экспорт-модалки — per-draft, Posts Manager — про посты, project-assets модуля — индекс диска с игрой, не загрузки. Скоуп v1 по слову Марти: **библиотека + вставка из неё + paste/drag&drop**; папки/теги/alt ассетов — потом.

**Decision.**
1. **Переиспользование = один URL во многих документах.** Вставка из библиотеки пишет существующий `/media/{LocalPath}` в новый документ; строка `Asset` одна, квота (`SUM(SizeBytes)`) считает её один раз. Дедуп по содержимому при загрузке (одинаковый файл дважды = две строки) — отложен, это оптимизация, не корректность.
2. **Удаление — on-demand скан, не таблица использований.** «Кто ссылается» уже умеет `CedarPackage.FindReferencedMediaPaths` — истина упаковки `.cedar`; заводить второй сканер значило бы две истины о том, что считается ссылкой. Скан идёт по `Draft.CedarJson` владельца **и всем переводам** (не первому — латентный пробел `GET /drafts/{id}/assets` чинится этим же коммитом); занятый ассет отвечает **409 с `[{draftId,title}]`**, свободный удаляется целиком: файл, Telegram-дериватив, строка. Стоимость скана ограничена числом документов владельца; usage-таблица — follow-up, если станет медленно на реальных объёмах.
3. **Новая страница `/library`** (Angular, authGuard, ссылка в навигации шелла; **не `/media`** — этот префикс уже целиком принадлежит URL самих загруженных файлов: серверная статика `RequestPath="/media"` и dev-прокси заворачивают его на бэкенд, что и поймал первый же e2e-прогон) по анатомии project-assets: грид/список, чипы типов со счётчиками, поиск по имени, пейджинг, шапка «занято/лимит» — данные приходят одним `GET /api/assets` (skip/take, `q`, фильтр типа; счётчики чипов — по нефильтрованному множеству).
4. **Вставка в редактор — отдельный лёгкий `media-picker`**, не реюз страницы: пикеру не нужны delete/usage, а `editor.component` и так огромен. Кнопка «библиотека» в insert-rail; вставка по `ContentType` (image/video/audio).
5. **Paste и drag&drop** в редакторе: `editorProps.handlePaste` (файлы из клипборда → whitelist типов → существующий upload с прогрессом → вставка) и `handleDrop` (то же, в точку дропа через `posAtCoords`). Прогресс-панель уже есть — переиспользуется.

**Consequence.** `CedarPackage` получает `FindReferencedMediaPathsSafe` (кривой JSON → пустой список, не исключение — скан не должен падать из-за одного битого документа). Удаление занятого файла невозможно по построению — сначала убрать из документов, потом удалить; формулировка 409 показывает, откуда именно. Отложено и записано на борде: папки/теги ассетов, alt-тексты, дедуп по хэшу, usage-таблица.
