# ADR-092 — Кошелёк кредитов: платные сети оплачивает автор, предоплаченными кредитами (04.08.2026)

**Context**: Марти решил строить X-коннектор (T-001 → Phase 12), а X с 06.02.2026 — pay-per-use: ~$0.015 за пост, ~$0.20 за пост со ссылкой (Cedar Clerk почти всегда постит со ссылкой на блог), и при shared-app модели платит владелец приложения — за посты всех тенантов. Перекладывать расход надо на автора; Марти выбрал предоплаченные кредиты (04.08.2026, три ответа: универсальный кошелёк / наценка ~2× / в планы ничего не включено).

**Decision: один универсальный кошелёк кредитов Cedar Clerk**, не счётчик «постов в X». Кредит — внутренняя валюта для всего, что стоит внешних денег: сейчас X-пост (1 кредит = 1 пост = $0.40 при себестоимости ~$0.20), позже другие платные сети и перерасход AI-квоты. Пакеты: **10 = $4, 50 = $18, 100 = $30** (Stars: 200/900/1500 ⭐ по калибровке 1⭐≈$0.02). Планы Pro/Pro Plus кредитов не включают — покупка строго отдельная, бонусы можно добавить потом, не ломая модель.

**Механика — леджер, не поле-баланс**: `CreditEntry` (OwnerId, Delta ±, Reason, Ref, CreatedAt), баланс = SUM. Плюсовые строки пишет покупка (Stripe one-time Checkout / Stars invoice — те же флоу, что планы, с дедупликацией по `Payment.ExternalId`), минусовые — успешная публикация. **Списание только за успешный пост**, идемпотентно по (Reason, Ref=PublishJob) — ретрай очереди (T-090) не списывает дважды. Недостаток баланса — читаемый отказ в окне экспорта до отправки, рядом с предупреждениями матрицы возможностей (T-086).

**Не сделано этим ADR**: PayPal-покупка пакетов (добавится по образцу, когда дойдут руки), возврат кредитов при удалении поста (пост в X уже оплачен — возврата нет), и сам X-коннектор — он получит собственный ADR при постройке (OAuth 2.0 PKCE с ротацией refresh token, подсчёт символов с t.co=23, медиа байтами).
