# ADR-231 — The public blog puts discovery and reading before its frame

## Context

The public index squeezes every tag between fixed-width controls. A modest tag
collection pushes the first post below the first screen. The post page gives its
wood frame and metadata as much emphasis as the article. Search disappears on a
phone, and some navigation drops the reader's language.

## Decision

1. Keep Cedar Bench paper, wood, olive, and both themes. Use a wider index and a
   restrained paper reader. Wood belongs to the site header and footer; the
   article has no outer board or decorative pins. This supersedes ADR-192's frame.
2. Put the index heading and result count above a search-and-order row. Languages
   and topics occupy a separate row. All topics are available in native `details`;
   selected filters remain visible outside it, with an explicit reset link.
   Search stays available on phones. Filters remain GET links and work without JS.
3. Give post titles and excerpts precedence over language badges and counters.
   Public cards can preview their first local image; gated cards never expose an
   image or excerpt. Images have a reserved size and lazy loading. There is no new
   remote image fetch on the index.
4. Keep the selected content language on card, search, and back links. Retain
   translation fallback and the existing owner/private visibility rules.
5. Put the discussion immediately after the article, followed by further reading
   and subscription. Keep the existing reaction, comment, subscription, and
   publication endpoints. Do not send mail or publish during design verification.
6. Export the existing integer type and spacing scales through the shared token
   contract so blog layout uses the same values without a second handwritten scale.
   Reading controls still change reading text only.

## Verification

Run `cedar test`. Check the real server-rendered pages against an isolated local
database at desktop and phone widths, in both themes. Exercise topic selection,
reset, search, language navigation, reading settings, and empty results. Verify
that private cards do not acquire previews. Production deployment is separate.
