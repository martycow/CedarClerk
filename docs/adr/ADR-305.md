# ADR-305 — Move to .NET 10 LTS

**Status**: DONE

## Context

.NET 8 leaves support in November 2026 (`T-072`). The primary development machine is macOS with only the .NET 10 SDK and runtime. Running the net8.0 test host there required `DOTNET_ROLL_FORWARD=Major`.

## Decision

All four projects target `net10.0`. Microsoft packages move from `8.0.*` to `10.0.*` (ASP.NET Core Identity, Google authentication, EF Core Sqlite and Design). Test packages move to current xUnit 2.9 and its 3.x runner. `TenantFilterGuardTests` reads filters through `GetDeclaredQueryFilters()`, which replaces the obsolete `GetQueryFilter()`.

EF Core 10 produced no model change: `SchemaDriftGuardTests` passes without a new migration.

## Consequences

- The droplet needs the ASP.NET Core 10 runtime in `~/.dotnet` **before the next deploy**. A net10 build on the 8.0 runtime fails to start.
- The deploy stays framework-dependent with no RID.
- ADR-001's ".NET 8 LTS" choice stands with the version updated.
