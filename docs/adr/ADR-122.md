# ADR-122 — `docs/admin-panel-scope.md` удалён; два его решения переезжают сюда (18.08.2026)

Файл был скоупингом админ-панели «что решить и в каком порядке строить». Все пять шагов построены 27.07.2026, гейт проверен Марти вживую в тот же день — с тех пор документ целиком в прошедшем времени: обсуждение живёт в git-истории файла, статус — в `ROADMAP.md`. Держать отдельный док ради двух живых фактов дороже, чем перенести их; переносятся дословно по смыслу:

1. **Аудит-лог append-only, retention отсутствует сознательно.** Лог админ-действий не подрезается: обрезка удалила бы ровно то, за чем в такой лог приходят. Пейджинг (`?skip=` + `hasMore`) есть с 27.07.2026 — рост лога проблема чтения, не хранения.
2. **Админ-гейт не покрыт автотестами и проверяется вживую.** HTTP-уровневых интеграционных тестов в проекте нет (`CedarClerk.Tests` — чистые хелперы и рендереры), так что 404 для не-админа на `/api/admin/*` и редирект `/admin` доказываются только живым заходом. Проверено 27.07.2026; **любое изменение гейта повторяет живую проверку** — автоматики, которая её заменит, не существует.
