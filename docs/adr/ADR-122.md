# ADR-122 — `docs/admin-panel-scope.md` deleted; its two decisions move here (18.08.2026)

The file was a scoping document for the admin panel — "what to decide and in what order to build". All five steps were built on 27.07.2026, the gate was checked live by Marty that same day — since then the document is entirely in the past tense: the discussion lives in the file's git history, the status lives in `ROADMAP.md`. Keeping a separate doc for the sake of two still-live facts costs more than moving them; they move verbatim in meaning:

1. **The audit log is append-only, with no retention by design.** The admin action log is never trimmed: trimming would delete exactly what such a log is kept for. Paging (`?skip=` + `hasMore`) has existed since 27.07.2026 — log growth is a reading problem, not a storage one.
2. **The admin gate is not covered by automated tests and is checked live.** The project has no HTTP-level integration tests (`CedarClerk.Tests` is pure helpers and renderers), so a 404 on `/api/admin/*` for a non-admin, and the `/admin` redirect, are proven only by a live visit. Verified 27.07.2026; **any change to the gate repeats the live check** — no automation that would replace it exists.
