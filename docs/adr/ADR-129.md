# ADR-129 — Storage quotas cut to what the disk can honor (18.08.2026)

**Context.** `docs/product/MULTITENANCY.md` §1: the droplet has ~40 GB free, while `PlanLimitations.StorageLimitBytes` promised Free 200 MB / Pro 8 GB / Pro Plus 16 GB — five Pro customers picking up their quota fill the server. T-172 named this a registration blocker with two steps: cut quotas now, move media to object storage (R2) before registration opens.

**Decision.** Marty confirmed MULTITENANCY's proposed figures: **Free 100 MB, Pro 1 GB, Pro Plus 3 GB**. Founder stays at 100 GB — it is not a sellable tier and the figure was not part of the decision. Raising a quota later is easy; lowering one under live users is not, so the launch numbers start at the floor.

**Consequence.** Step 2 of T-172 (media into Cloudflare R2, `/media/*` becomes a redirect/proxy to a signed URL) remains open and is still the real fix — the honest quotas only make the interim arithmetic sound. The landing prices table reads these values via `PlanLimitations`, so it updates itself.
