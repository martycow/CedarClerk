# ADR-100 — Short-post language is chosen per network (09.08.2026)

**Context**: Marty's request. ADR-096 made the version selection shared for the window, and X and Bluesky sent **every** checked version: two checkboxes in the "Version" step — two tweets from one account, two credits (ADR-092). That's correct for Telegram (versions have different channels, ADR-098), almost never for a single X account.

**Decision: the X and Bluesky panel has its own set of languages — a subset of those checked in the "Version" step.** By default it matches that set in full (behavior doesn't change silently), and the row of pills only appears once there's more than one version. An entirely unchecked selection is forbidden — the target is checked, meaning something goes out.

**Why a subset rather than a single language**: an account can have a bilingual audience, and "both" is a legitimate choice. Limiting to one language would save a click and forbid a real scenario.

**Consequence**: the cost of publishing to X (`xCreditCost`) is counted by **this network's** languages, not by the window's checked versions — until now it was overcounted in exactly the situation where the network was sending extra.
