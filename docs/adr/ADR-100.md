# ADR-100 — Язык короткого поста выбирается на сеть (09.08.2026)

**Context**: запрос Марти. ADR-096 сделал выбор версий общим для окна, и X с Bluesky отправляли **каждую** отмеченную версию: две галочки в шаге «Версия» — два твита с одного аккаунта, два кредита (ADR-092). Для Telegram это правильно (у версий разные каналы, ADR-098), для одного аккаунта в X — почти никогда.

**Decision: у панели X и Bluesky свой набор языков — подмножество отмеченных в шаге «Версия».** По умолчанию совпадает с ним целиком (поведение не меняется молча), ряд пилюль появляется только когда версий больше одной. Снятая всюду галочка запрещена — назначение отмечено, значит что-то уходит.

**Почему подмножество, а не один язык**: у аккаунта может быть двуязычная аудитория, и «оба» это законный выбор. Ограничение до одного языка сэкономило бы клик и запретило бы реальный сценарий.

**Следствие**: стоимость публикации в X (`xCreditCost`) считается по языкам **этой сети**, а не по отмеченным версиям окна — до сих пор она завышалась ровно в той же ситуации, в которой сеть отправляла лишнее.
