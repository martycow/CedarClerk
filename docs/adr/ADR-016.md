# ADR-016 — Comment moderation: delete-after-the-fact, not an approval queue
**Decision**: Blog comments are simple and unmoderated at post time; the channel owner can delete any comment after publication from a right-side panel in the editor. No pending/approval queue exists.
**Consequence**: Comments appear on the blog immediately on submission. Anti-abuse for reactions relies on `VisitorHash` (derived from `CF-Connecting-IP` + salt, no raw IP stored) rather than moderation gating.
