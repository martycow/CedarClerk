# ADR-007 — Telegram renderer: HTML-only, Markdown/HTML hybrid dropped
**Context**: Early Phase 3 renderer work considered a hybrid Markdown+HTML approach after an initial (mistaken) belief that Telegram's HTML mode didn't support block tags.
**Decision**: That belief was a verification error (wrong test channel). `CedarToTelegramHtmlRenderer` (HTML-only) is canonical; the Markdown hybrid was dropped. A separate `CedarToTelegramMarkdownRenderer` exists as an export *format option*, not as part of the send pipeline's HTML/Markdown alternative.
**Consequence**: All the Telegram HTML-mode quirks (non-void tag closing, block tag support) in `.claude/rules/telegram-bot.md` apply directly to the canonical renderer.
