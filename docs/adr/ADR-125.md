# ADR-125 — Серии постов: сущность, а не тег (18.08.2026)

**Context.** «Devlog #1..#N» — прямо по devlog-first позиционированию: читатель, пришедший на часть 7, должен одним кликом попасть к части 1 и к странице всей серии (T-178, PUB-04 из Input sweep). Дешёвый вариант «серия = специальный тег» рассматривался и отклонён: у тега нет идентичности — нет стабильного slug'а для страницы, нет порядка (теги — плоская строка), и «часть N из M» из него не выводится.

**Decision.**
1. **`Series` — сущность** per-owner: имя, slug (через существующий `SlugGenerator`, уникален на владельца), описание; черновик привязывается парой `Draft.SeriesId` + `Draft.SeriesOrder` (оба nullable, ставятся и чистятся вместе — привязка назначает `max+1`, отвязка обнуляет оба). Порядок показа — `(SeriesOrder, BlogPublishedAt)`: явный порядок побеждает, дата — честный fallback для строк одной волны. Ручной reorder отложен — до него порядок привязки совпадает с порядком написания.
2. **URL — `/series/{slug}`** на блог-хосте: первая двухсегментная ветка в `HandleRequest` (до этого ≥2 сегментов означали 404). Лендинг серии строится по образцу тег-лендинга и показывает **ровно то, что показывает индекс**: `IsBlogPublished && (!IsPrivate || IsListedWhilePrivate)`, приватные карточки — с замком и без тизера. Пустая или полностью приватная серия — не 404, а честный пустой лендинг.
3. **На странице поста**: строка серии над заголовком («часть N из M», N считается по видимому упорядоченному списку — приватный невидимый пост не сдвигает нумерацию для чужих глаз) и блок prev/next по тем же соседям. RSS не меняется.
4. Управление — целиком по образцу папок (77-строчные эндпоинты, сервис с latch, пикер): `GET/POST/PUT/DELETE /api/series` + `PUT /api/drafts/{id}/series`; удаление серии отвязывает черновики, не трогая их.

**Consequence.** Связь серии с проектом модуля (витрина T-159) — следующий шаг, не этот: серия living per-owner и не знает о `Project`. Нумерация «часть N из M» пересчитывается на каждый рендер — хранить её значило бы чинить её при каждой перепубликации соседа.
