# ADR-251 — The initial-bundle ceiling follows the measured bilingual shell (02.09.2026)

**Context.** The production build on `master` measures 819.00 kB against an 820 kB error ceiling.
The collection controls, unified Preferences surface and compact document navigation add bilingual
labels and shared interaction code to the authenticated shell. The resulting initial bundle is
833.61 kB. Moving these controls behind page-local lazy routes would require splitting the shared
localization dictionary first; that is a separate architecture change, not a safe optimization to
hide inside this interface pass.

**Decision.** The production initial-bundle error ceiling is 850 kB. This leaves 16.39 kB, or less
than two percent, above the measured build. The 700 kB warning remains unchanged and T-363 stays
open. Future features still need lazy routes where a page can own its code, and the localization
dictionary remains the first candidate for reducing the initial bundle.

**Rejected.** *Leave the build red* — a feature branch that cannot produce a production bundle is
not complete. *Raise or remove the warning* — the warning correctly records accumulated debt.
*Split localization during this pass* — it changes startup and translation loading across the
whole product without belonging to the requested interface work.

**Consequence.** `cedar build` can package the measured bilingual shell while preserving a narrow
hard limit and a visible warning. Crossing 850 kB is still a release failure. T-363 owns the larger
work of bringing the shell back below the warning rather than repeatedly moving that signal.
