Three switches, three different mechanisms. Theme sets data-theme on the document (ThemeService, persisted). Density sets data-density on this page's root — a property of a page, never of a component. Surface sets data-surface on the demo bays below and on nothing else: chrome and paper are two densities living on one screen (ADR-138), so the surface is a material an element is made of, not a mode a screen is in. Compact chrome is still chrome — the two vocabularies never declare each other's tokens, which npm run check:density enforces.

Buttons

app-button — four variants, two sizes. The surface is read off the variant, not off the size: rail is the only one painted on wood, so it is the only one that takes chrome's 30px box and 13/11px type. On paper both sizes hold --hit-target (44px), which is why sm there tightens the padding and nothing else. danger is a destructive action, not an error state — it is a dashed-underlined word, never a filled red button, so that deleting something never looks like the primary thing to do. Stamps, drops and leaves

app-stamp-badge says what state a thing is in and never acts — it takes no click and carries no role, so it cannot quietly become a button. Each tone's wash is mixed from its own ink on ADR-145's formula, so ink and wash are a pair the contrast checker can score. app-resin-drop is the only save indicator in the system: no spinner, no "saving…" toast, and never on a button. It is role="status", which is what removes the need for the toast. app-leaf-tag labels and filters; dried means no data or switched off and never an error — an error is a rust stamp, and nothing in the leaf reaches for --danger.

Paper and tags

app-paper-card is the surface ink lies on — never glassy, never blurred, never a large radius, and its whole hover language is a 2–3px lift on --ease-swing. A deckled sheet is cut with clip-path, and a clipped box casts no box-shadow at all, so the drop is a filter on a wrapper. app-task-tag hangs from a hook: only the date turns rust when overdue — never the tag and never the rail it hangs on — and done fades it to 62% rather than striking the text through, because a struck-out task is unreadable and a faded one is finished.

Inspector rows

app-spec-row is one ruled line of a printed spec sheet, stacked inside a shelf panel. The inspector is contextual — it describes the selected object, and falls back to the document when nothing is selected — and it must never show both at once, so every row declares whose property it is through scope. A mixed sheet is then one query rather than a convention nobody can check. Rows are chrome wherever they stand, which is why this bay does not follow the surface toggle.

Hardware

Brass is hardware, not a palette: neither piece takes a colour and neither takes a size, because a pin stops reading as a pin much past 16px. app-brass-pin holds down anything that lies on a surface — a card, a leaf. app-brass-hook carries anything that hangs — a task tag, a tool on the rail. Picking the wrong one breaks the physical logic of the workshop, which is why they are deliberately not interchangeable: different sizes, different APIs. The pin is silent by default and takes a role and a name only when it is the sole thing saying a card is pinned; the hook is never named, because whatever hangs from it carries the name.

Error and warning

Four primitives carry one, and each says something different: a destructive action, a failed state, a date that has passed, a value that is missing. The other five have none, and two of them have none on purpose — app-leaf-tag's dried means "no data", and app-resin-drop has no busy or failed state because its whole union is two values. app-input has no error state at all: the design system's field has no error prop either, so a form validating today has nowhere to put the message. That is a gap in the kit, not a gap on this page.

Focus ring

One global rule, two layers: a --brass-edge outline at 2px offset inside a cream --focus-halo (ADR-140). Two layers because no single colour clears 3:1 on both families — flat brass measures 1.86:1 on the ruler it is drawn from, and flat accent measures 1.00:1 on a pine button. The dark outline against the cream halo is a constant 4.20–6.91:1 boundary inside the band whatever lies underneath, so one rule covers every surface. Its stated cost: a focused control gives up its own box-shadow, which is why every shadow in the kit is written :not(:focus-visible).
