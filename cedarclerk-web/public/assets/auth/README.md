# Authentication artwork

`forest-background.webp` is a decorative background derived from the selected Cedar Clerk forest sign-in prototype using the built-in OpenAI image-generation tool.

- Dimensions: 1920 × 1440.
- Encoding: WebP, quality 88. The 1448 × 1086 source was resized with Lanczos resampling.
- Reference image: `exec-7b29795b-e1e9-4a2e-a0b3-12c3ef530553.png`.
- Generated source: `exec-70bb3f32-f70d-4950-aa1e-97f302940e6e.png`.

Generation brief: remove all interface elements, logos, and text from the reference; preserve the muted olive engraved cedar trees at the edges, distant hills, and quiet warm charcoal sky. Fill the removed card with a continuous landscape. Output forest artwork only, without additional objects or lettering.

Keep this image decorative. Text, controls, and identity marks belong in the interface.

`cedar-sprig.webp` is a generated transparent cedar sprig and pinecone ornament, downsampled to 320 x 200. It is decorative and carries empty alternative text.

`google-g.png` is the unmodified Google identity asset from https://developers.google.com/static/identity/images/g-logo.png, used only to identify Google sign-in.

`bookmark.svg` is the unmodified Phosphor bookmark-simple fill asset from the existing @phosphor-icons/core dependency (MIT); used as a decorative coral paper marker.
